Version 3.1.5 (patch; same payload as mis-tagged **3.2.0**) - **Boosted state entry:** Mind Blowing / Lunar Phase Mode A now pushes `reisen_boost_triggered` when the kill-HP pool is at cap (`accum >= REISEN_RELEASE_HEAL_ACCUM_CAP`), and `reisen.lua` handles it via `reisen_on_booster_applied` (replaces `reisen_mindblowing_killed`, which required an AoE kill at max stack). **Skills:** `ReisenPayCost` blocks all paid skills when hunger ≤ 0. **ReleaseHeal:** returns `true` (no effect) on stack=0, Slow Field stack shortfall, or cost failure so client `castspellmind` never desync-freezes when net vars disagree with the server. **Client / Moon Charm:** grey-vision suppression uses `ReisenMooncharmEquipped()` whenever the charm is worn (not only full immunity); `PlayerHud:GoInsane` clears PostProcessor greyness for charm wearers, keeps vig “insane” animation when `inducedinsanity` overrides immunity (e.g. nightmare amulet), and resets vig for broken-immunity crazy (full moon, starvation, overwhelm); charm equip defers `GoSane` if `replica.sanity:IsCrazy()` so the insanity frame stays correct.
